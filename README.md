# 🎀 It Girl Club

Um espaço para explorar estilos, descobrir inspirações e encontrar looks que combinam com sua personalidade.

O **It Girl Club** é um projeto de desenvolvimento web voltado ao universo da moda, criado para proporcionar uma experiência interativa de descoberta e inspiração. A proposta é reunir referências de looks, apresentar diferentes estilos e ajudar cada visitante a explorar sua própria identidade visual.

## Sobre o projeto

A ideia do It Girl Club é transformar a descoberta de estilos em uma experiência leve, visual e intuitiva.

Por meio de um catálogo de looks e de um quiz interativo, a visitante poderá conhecer diferentes referências de moda, identificar estilos com os quais mais se identifica e encontrar inspirações para diversas ocasiões.

O projeto também busca valorizar a organização visual, a responsividade e a facilidade de navegação.

## Funcionalidades

O projeto prevê as seguintes funcionalidades:

- **Catálogo de looks:** exploração de referências de moda organizadas por categorias.
- **Quiz de estilo:** perguntas interativas para identificar os estilos que mais combinam com as preferências da visitante.
- **Resultado personalizado:** apresentação do estilo predominante, estilos complementares e inspirações relacionadas.
- **Inspirações para eventos:** referências de looks para datas comemorativas e ocasiões especiais.
- **Tema claro e escuro:** possibilidade de alternar a aparência do site.
- **Design responsivo:** adaptação da interface para computadores, tablets e celulares.

| Tecnologia | Aplicação |
|---|---|

O projeto utiliza JavaScript puro (*Vanilla JavaScript*), sem frameworks.

## Como executar o projeto

Por utilizar HTML, CSS e JavaScript, o projeto não exige instalação de dependências ou configuração de backend.

1. Clone o repositório:

```bash
git clone https://github.com/RafaApS/it-girl-club.git
```

2. Acesse a pasta:

```bash
cd it-girl-club
```

3. Abra o arquivo `index.html` no navegador ou utilize uma extensão de servidor local, como o Live Server, no Visual Studio Code.
